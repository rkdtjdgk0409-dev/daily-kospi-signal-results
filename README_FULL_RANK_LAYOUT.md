# Price Structure V5 — Full Rank Layout

## 변경 목적
브라우저 확대/축소 비율에 따라 왼쪽 종목 랭킹 목록의 표시 개수가 달라지고,
패널 아래에 빈 공간이 생기던 문제를 수정했습니다.

## 핵심 변경
- 왼쪽 랭킹 테이블의 `76vh / 48vh` 높이 제한 제거
- 랭킹 목록의 내부 세로 스크롤 제거
- 필터에 걸린 종목은 모두 문서 높이만큼 자연스럽게 표시
- 브라우저 확대/축소로 반응형 breakpoint가 바뀌어도 목록을 다시 잘라내지 않음
- 좌/우 패널을 `align-items:start`로 바꿔 한쪽 패널 높이에 다른 패널이 억지로 늘어나지 않게 함
- 가로 폭이 부족할 때의 가로 스크롤은 유지

## 적용 범위
- 한국 Price Structure 페이지
- 미국 Price Structure 페이지
