# M-able Wide 스타일 차트 조작 V2

이번 패치는 기존 종목 스캔 → 독립 stock.html 구조를 유지하면서, 상세 캔들 차트의 조작성과 가독성을 M-able Wide와 비슷한 방향으로 개선합니다.

## 핵심 변경
- 차트 상단 고정 OHLC 바: 십자선/마우스로 가리킨 캔들의 시가·고가·저가·종가·등락률 표시
- 상승 캔들 빨강 / 하락 캔들 파랑으로 변경
- 십자선(spike line) 추가
- 기본 조작은 `이동`, 필요 시 `영역확대` 모드 전환
- `+ / -` 버튼으로 캔들 밀도 확대·축소
- 마우스 휠은 가로축(캔들 수) 중심 확대·축소
- 확대/이동 후 보이는 구간에 맞춰 가격축 자동 재조정
- `가격맞춤`, `초기화`, `전체화면` 버튼 추가
- 2M / 3M / 6M / 1Y / 전체 빠른 기간 선택
- 레이어(매물대/파동/채널/매매포인트/예상경로/Fib)를 껐다 켜도 사용자가 보던 확대 구간 유지
- 마지막 종가를 현재가 점선/가격 라벨로 표시
- 모바일 차트 높이 확대 및 조작 버튼 가로 스크롤 대응

## 적용 파일
1. `price_structure_workspace.py` 신규/교체
2. `price_structure_build_page.py` 교체
3. `us_price_structure_build_page.py` 교체

기존 `pages.yml` 실행 순서는 변경할 필요가 없습니다.
