# M-able형 차트 V3 변경사항

이번 버전은 차트 축과 hover 동작을 KB증권 M-able Wide 형태에 더 가깝게 정리한 버전입니다.

## 변경된 차트 동작

- 하단 X축은 거래일을 모두 쓰지 않고 `YYYY/MM` 형식의 연/월만 표시합니다.
- 확대/축소 또는 좌우 이동 시 현재 보이는 구간을 기준으로 월 라벨을 자동 재배치합니다.
- 캔들에 마우스를 올리면 점선 세로선 + 점선 가로선이 동시에 나타납니다.
- 십자선 아래에는 `YYYY/MM/DD` 형식으로 정확한 거래일이 나타납니다.
- 십자선 오른쪽에는 현재 커서가 가리키는 가격이 표시됩니다.
- 차트 상단 OHLC 바는 종목명 옆에 시가/고가/저가/종가와 전일 종가 대비 등락률을 함께 표시합니다.
- 마우스를 다른 캔들로 이동할 때마다 상단 OHLC 값이 즉시 해당 봉 기준으로 변경됩니다.
- 캔들 wick 끝의 가로 cap을 제거하여 고가/저가 선이 T자형이 아니라 일자형(I형)으로 끝나도록 수정했습니다.
- 상승 캔들 빨강 / 하락 캔들 파랑, 이동/영역확대/휠 줌/가격 맞춤/전체화면 기능은 기존 V2와 동일하게 유지합니다.

## 적용 파일

레포지터리 루트에서 아래 3개 파일을 사용하면 됩니다.

1. `price_structure_workspace.py` 새 공통 UI 빌더
2. `price_structure_build_page.py` 한국 시장 빌더
3. `us_price_structure_build_page.py` 미국 시장 빌더

GitHub Actions의 기존 실행 순서는 변경할 필요가 없습니다.
